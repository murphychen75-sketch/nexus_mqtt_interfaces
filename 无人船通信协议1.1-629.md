## 1. 协议规范

### 1.1 基础信息

| 项目         | 规范                |
| ------------ | ------------------- |
| 协议版本     | 2.0                 |
| 传输协议     | MQTT 5.0            |
| 服务器地址   | 39.107.52.182:18055 |
| 数据编码     | UTF-8               |
| Payload 格式 | JSON                |

### 1.2 产品与设备抽象

+ 产品是独立完整功能设备的抽象综合。
+ 产品分为：直连设备、网关设备、网关子设备。
+ 直连设备具备独立 IP，且不能外接设备。
+ 网关设备具备独立 IP，并可关联多个子设备。
+ 网关子设备没有独立 IP，通过网关设备代收发数据。
+ 设备必须从属于产品，并归属到总产品（船设备）。总设备即 M10 或 NEUXS 船舶总产品。
+ 本文的 `productKey/deviceName` 按可迁移的功能设备展开，例如 `gps/gps_01`、`io/io_01`、`ais/ais_01`。

### 1.3 统一消息结构

所有 MQTT 消息采用统一外层包裹格式：

```json
{
  "id": "msg-uuid-xxx",
  "reportTime": 1703123456789,
  "deviceId": "Dv8uXewHC5N9PsBz.mcu_test_001",
  "tenantId": "tenant_xxx",
  "requestId": "req-uuid-xxx",
  "method": "thing.property.post",
  "params": {
    // 业务字段在此
  }
}
```

| 字段         | 类型   | 说明                                           |
| ------------ | ------ | ---------------------------------------------- |
| `id`         | string | 消息唯一标识（UUID）                           |
| `reportTime` | int64  | 消息生成/发布时间戳，单位：毫秒                |
| `deviceId`   | string | 设备唯一标识，格式 `{productKey}.{deviceName}` |
| `tenantId`   | string | 租户标识                                       |
| `requestId`  | string | 消息唯一标识（UUID）                           |
| `method`     | string | 方法名，见 §2.1 各类型对应 method              |
| `params`     | object | 业务参数，不同 method 对应不同结构             |

**响应消息额外字段**：

| 字段   | 类型   | 说明                      |
| ------ | ------ | ------------------------- |
| `code` | int    | 状态码，0 或 200 表示成功 |
| `msg`  | string | 响应描述信息              |

### 1.4 通用字段与时序约定

| 字段                                | 约定                                   |
| ----------------------------------- | -------------------------------------- |
| `reportTime`                        | MQTT payload 生成/发布时间，单位：毫秒 |
| `params.data.ts`                    | 传感器或执行器原始采样时间，单位：毫秒 |
| `params.time`                       | 事件发生时间，单位：毫秒               |
| `timestamps[].time`                 | 算法流水线阶段时间，单位：毫秒         |
| `trajectories[].points[].timestamp` | 轨迹点对应的观测时间，单位：毫秒       |

### 1.5 设备订阅策略

设备端订阅通配 Topic 接收所有下行消息：

```
/sys/{productKey}/{deviceName}/#
```

该订阅覆盖属性设置、服务调用、配置推送等所有下行消息，设备无需逐一订阅。

## 3. 下行数据格式（云 → 设备）

### 3.1 服务调用通用格式

云平台通过 `thing.service.invoke` 向设备下发指令：

**Topic**：`/sys/{productKey}/{deviceName}/thing/service/invoke`

```json
{
  "id": "req-uuid-001",
  "reportTime": 1703123456789,
  "deviceId": "jetson.jetson_01",
  "tenantId": "tenant_xxx",
  "requestId": "req-uuid-001",
  "method": "thing.service.invoke",
  "params": {
    "identifier": "estop",
    "inputParams": {
      "estop": true,
      "src": "shore"
    }
  }
}
```

| 字段          | 类型   | 说明                                     |
| ------------- | ------ | ---------------------------------------- |
| `identifier`  | string | 服务标识符，区分不同指令类型             |
| `inputParams` | object | 服务输入参数，由具体 identifier 决定结构 |

### 3.2 服务调用响应通用格式

设备通过 `thing.service.invoke_reply` 返回服务执行结果：

**Topic**：`/sys/{productKey}/{deviceName}/thing/service/invoke_reply`

```json
{
  "id": "resp-uuid-001",
  "reportTime": 1703123456800,
  "deviceId": "jetson.jetson_01",
  "tenantId": "tenant_xxx",
  "requestId": "req-uuid-001",
  "method": "thing.service.invoke",
  "params": {
      "identifier": "estop",
    "inputParams": {
      "estop": true,
      "src": "shore"
    }
  },
  "code": 0,
  "msg": "success"
}
```

## 7. 子设备注册与拓扑管理

### 7.1 子设备注册

网关设备通过注册接口向平台注册子设备（仅获取 DeviceSecret，不创建新设备，设备需预先在平台创建）：

**Topic**：`/sys/{productKey}/{deviceName}/thing/sub/register`

```json
{
  "id": "sub-xxx",
  "reportTime": 1703123456789,
  "deviceId": "jetson.jetson_01",
  "tenantId": "tenant_xxx",
  "requestId": "sub-xxx",
  "method": "thing.sub.register",
  "params": {
    "subs": [
      { "productKey": "gps", "deviceName": "gps_01" },
      { "productKey": "imu", "deviceName": "imu_01" }
    ]
  }
}
```

### 7.2 子设备注册响应

**Topic**：`/sys/{productKey}/{deviceName}/thing/sub/register_reply`

```json
{
  "code": 0,
  "msg": "success",
  "params": {
    "subs": [
      { "productKey": "gps", "deviceName": "gps_01", "deviceSecret": "secret_xxx" },
      { "productKey": "imu", "deviceName": "imu_01", "deviceSecret": "secret_yyy" }
    ]
  }
}
```

### 7.3 拓扑获取

**Topic**：`/sys/{productKey}/{deviceName}/thing/topo/get`

```json
{
  "id": "topo-xxx",

  "deviceId": "jetson.jetson_01",
  "tenantId": "tenant_xxx",
  "requestId": "topo-xxx",

}
```
